Privacy Policy

Last updated: October 2026

What this app is

auto-shorts is a personal tool used only by its owner to upload videos to the owner's own YouTube channel through the YouTube Data API.

Data we access

The app requests only the permission to upload videos (youtube.upload) to the owner's own YouTube channel. It does not read, collect, or store any other personal information from any user.

How data is used and stored

An authorization token is stored privately as an encrypted secret in the owner's own account, and is used only to upload the owner's videos. No user data is sold, shared with third parties, or used for advertising.

YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's privacy policy is available at https://policies.google.com/privacy.

Revoking access

Access can be removed at any time at https://myaccount.google.com/permissions.
